# ADR 0009: 포인트 컬러는 앰버 (#F59E0B)

**Status:** Accepted · 2026-04-09

## Context

CTA, 활성 필터, 선택된 마커, 브랜드 표현에 사용할 단일 포인트 컬러 필요. 라이트 베이스 테마에 어울려야 함.

## Decision

**Amber-500 (#F59E0B)** — Tailwind 팔레트.

## Alternatives

- **블루** (#2563EB) — 신뢰, 안정감. 너무 흔함 — 다른 한국 지도/파인더 앱과 똑같은 컬러.
- **오렌지-500** (#F97316) — 따뜻하지만 과하게 채도 높음. 지도 색상과 경쟁.
- **그린** (#22C55E) — 웰니스 느낌. 하지만 "신선/건강"을 암시 → "힘/철"과 거리.

## Consequences

**긍정적:**

- "IronSpot"이라는 이름의 철/금속 따뜻함과 앰버의 황금-갈색 톤이 조화
- 라이트 베이스에서 또렷하게 부각
- 앰버 계열 (300/500/600/50)이 전체 인터랙션 상태를 커버
- 오렌지보다 따뜻함, 프리미엄한 느낌 (놀이보다 실용)
- 파란색 일색의 지도 앱 시장에서 차별화

**부정적:**

- 앰버/오렌지는 지도 요소와 구분이 어려울 수 있음 (선택된 마커는 `amber-600` + 흰 텍스트 배지로 대비 처리)
- 색맹 사용자 테스트 필요 (앰버/그린 조합은 안전, 레드-앰버는 아이콘+텍스트 동반 필요)
