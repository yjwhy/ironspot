# ADR 0015: 한국 시장 타겟이므로 네이버 지도 SDK 사용

**Status:** Accepted · 2026-04-15

## Context

한국 유저 대상 헬스장 파인더 앱. 지도 데이터 품질 (주소, 건물명, POI 정확도) 중요. React Native 호환 지도 SDK 필요.

## Decision

**네이버 지도 SDK.**

## Alternatives

- **Google Maps** — 글로벌 표준. 어디서든 가입 가능. 모바일 SDK 렌더링은 무료 (웹 Maps API와 달리). 하지만 한국 주소/건물명 정확도가 조밀한 도심 지역 (강남, 홍대 등)에서 네이버 대비 크게 떨어짐.
- **Kakao Maps** — 한국 커버리지 좋지만 React Native SDK 지원이 네이버 대비 약함 (커뮤니티 라이브러리 유지보수 상태 미흡).

## Consequences

**긍정적:**

- 한국 주소/POI 데이터 정확도 최고
- 유저가 이미 네이버 지도 UI에 익숙
- 무료 티어가 우리 규모에 충분 (일 100,000 호출)
- Places API로 "새 헬스장 등록" 플로우 구현 가능

**부정적:**

- 네이버 클라우드 플랫폼 가입 시 한국 주소 필요 (한국 외 거주 개발자에게 블로커)
- 우회: 한국 친구가 계정 생성, API 키 공유
- 글로벌 확장 시 사용 불가 (Google Maps 추가 필요)

## 마이그레이션 경로

추후 글로벌 확장 시 Google Maps를 보조 provider로 추가하여 지역 감지 분기 (`한국 → 네이버, 그 외 → Google`) 가능. 서비스 레이어 추상화 덕분에 구현 가능.
