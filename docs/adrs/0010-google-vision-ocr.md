# ADR 0010: OCR은 Tesseract 대신 Google Vision API

**Status:** Accepted · 2026-04-09

## Context

Phase 2에서 유저가 업로드한 사진으로부터 헬스장 머신의 브랜드/모델 자동 인식이 필요함. 실제 조건: 양각 로고, 금속 표면, 다양한 각도, 헬스장 조명.

## Decision

**Google Vision API** — 월간 호출 제한 (900회) + 수동 입력 폴백.

## Alternatives

- **Tesseract.js** — 무료, 오픈소스, 클라이언트 실행. 하지만 양각/금속 로고에서 정확도 40-60%로 낮음. 이 유스케이스에선 낮은 정확도 = 나쁜 UX = 기능이 없는 게 나음.
- **AWS Rekognition** — Google Vision과 정확도 비슷하지만 설정 복잡.
- **커스텀 ML 모델** — 1인 프로젝트에 오버엔지니어링.

## Consequences

**긍정적:**

- 헬스장 머신 사진에서 85-95% 정확도 (리서치 결과)
- Logo Detection 기능이 별도 제공되어 브랜드 인식에 특화
- 월 1,000회 무료로 MVP 시연 용도 충분
- 빠른 응답 (1-3초)

**부정적:**

- Google Cloud 계정 + 결제 수단 등록 필요
- 과금 방지를 위한 하드 리밋 필수 (서버에서 월 900회로 제한)
- 네트워크 의존 (오프라인 OCR 불가) — 업로드 자체가 네트워크 필요하므로 수용 가능

## 과금 방지 안전장치

서버에서 월간 호출 횟수 카운팅. 900회 도달 시 OCR 비활성화 + 수동 입력 폴백. 예기치 못한 과금 가능성 원천 차단.
