Discovered while inspecting prod schema via Supabase MCP `list_tables`:

- **`users.deleted_at` missing in prod** — Phase 2 Task 30 (PR #45 cf5dcbd) added the column to `init-test-db.sql` and shipped `UserRepository.findById` / `markDeleted` referencing it, but the prod schema doesn't have it. - **`reports.status` is a Postgres enum in prod, `TEXT` in test schema** — JOOQ generates `String` from the test schema; prod accepts string-cast values fine, no immediate impact, but test fixtures can't reproduce constraint violation tests for invalid status values.
